# BookManager Models

BookManager에서 사용하는 런타임 모델 번들을 배포하는 저장소입니다. 대용량 모델은 Git 이력에 커밋하지 않고 GitHub Release 자산으로 제공합니다.

## Supertonic 3

- 원본: [Supertone/supertonic-3](https://huggingface.co/Supertone/supertonic-3)
- 고정 리비전: `724fb5abbf5502583fb520898d45929e62f02c0b`
- 모델 라이선스: OpenRAIL-M
- 배포 파일: [supertonic-3-724fb5a Release](https://github.com/dongkkase/BookManager-Models/releases/tag/supertonic-3-724fb5a)

각 Release에는 압축 파일, SHA-256 체크섬, 파일별 매니페스트가 포함됩니다. 모델 원본 라이선스와 출처 고지는 압축 파일에도 함께 포함합니다.
